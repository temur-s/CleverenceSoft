## 📝 Задача 1. Алгоритм сжатия строк

Реализован эффективный алгоритм сжатия и декомпрессии строк, состоящих из строчных латинских букв. 

### ⚙️ Принцип работы
* Группы идущих подряд одинаковых символов заменяются на формат `sc`, где:
  * `s` — исходный символ.
  * `c` — количество повторений символа.
* > [!IMPORTANT]
  > Если символ встречается в группе ровно один раз, то количество повторений не пишется (только сам символ).

### 📊 Примеры работы

| Исходная строка (оригинал) | Сжатый вид |
| :--- | :--- |
| `aaabbcccdde` | `a3b2c3d2e` |
| `a` | `a` |
| `abcd` | `abcd` |
| `zzzzzzzzzz` | `z10` |

## 📝 Задача 2. Многопоточный "Сервер"

Реализация потокобезопасного обращения к общему целочисленному ресурсу `count`. Класс спроектирован с учетом высоких нагрузок на чтение и нечастых операций записи.

### ⚙️ Требования и решение
* **Параллельное чтение:** Множество потоков-читателей могут одновременно вызывать `GetCount()` без взаимных блокировок.
* **Последовательная запись:** Потоки-писатели вызывают `AddToCount(int value)` строго по очереди (монопольно).
* **Приоритет записи:** Во время записи читатели приостанавливают чтение и ждут её завершения.

Для реализации выбран высокопроизводительный синхронизатор **`ReaderWriterLockSlim`** в стандартном режиме, что исключает возможность состояния гонки (race conditions) и минимизирует накладные расходы по сравнению с обычным `lock`.

## 📝 Задача 3. Стандартизатор логов

Консольное приложение для парсинга, валидации и приведения разноформатных файлов логирования к единой структуре.

### 📥 Входные форматы

Программа поддерживает два входных формата логов:

#### **Формат 1 (Пробелы в качестве разделителей)**
```text
10.03.2025 15:14:49.523 INFORMATION Версия программы: '3.4.0.48729'
```
* **Дата:** `10.03.2025` (в формате `DD.MM.YYYY`)
* **Время:** `15:14:49.523`
* **Уровень:** `INFORMATION`
* **Сообщение:** `Версия программы: '3.4.0.48729'`

#### **Формат 2 (Разделение через `|`)**
```text
2025-03-10 15:14:51.5882| INFO|11|MobileComputer.GetDeviceId| Код устройства: '@MINDEO-M40-D-410244015546'
```
* **Дата:** `2025-03-10` (в формате `YYYY-MM-DD`)
* **Время:** `15:14:51.5882`
* **Уровень:** `INFO` (с возможными пробелами по краям)
* **Вызвавший метод:** `MobileComputer.GetDeviceId`
* **Сообщение:** `Код устройства: '@MINDEO-M40-D-410244015546'`

---

### 📤 Выходной формат

Все логи приводятся к единому стандарту с разделением полей символом **табуляции (`\t`)**:

$$\text{Дата} \quad \backslash\text{t} \quad \text{Время} \quad \backslash\text{t} \quad \text{Уровень} \quad \backslash\text{t} \quad \text{ВызвавшийМетод} \quad \backslash\text{t} \quad \text{Сообщение}$$

1. **Дата:** Всегда преобразуется в формат `DD-MM-YYYY` (например, `10-03-2025`).
2. **Время:** Переносится без изменений.
3. **Уровень:** Стандартизируется согласно маппингу:
   * `INFORMATION` / `INFO` ➡️ `INFO`
   * `WARNING` / `WARN` ➡️ `WARN`
   * `ERROR` ➡️ `ERROR`
   * `DEBUG` ➡️ `DEBUG`
4. **Вызвавший метод:** Если отсутствует во входной записи, заменяется на `DEFAULT`.
5. **Сообщение:** Переносится без изменений.

> [!WARNING]
> Если входная запись повреждена или не соответствует ни одному из форматов (например, содержит некорректную дату или неизвестный уровень логирования), она записывается в исходном виде в файл `problems.txt`.

### 🔄 Пример преобразования

**Входной лог:**
```text
10.03.2025 15:14:49.523 INFORMATION Версия программы: '3.4.0.48729'
2025-03-10 15:14:51.5882| INFO|11|MobileComputer.GetDeviceId| Код устройства: '@MINDEO-M40-D-410244015546'
```

**Выходной лог:**
```text
10-03-2025	15:14:49.523	INFO	DEFAULT	Версия программы: '3.4.0.48729'
10-03-2025	15:14:51.5882	INFO	MobileComputer.GetDeviceId	Код устройства: '@MINDEO-M40-D-410244015546'
```

## 🚦 Запуск тестов и проектов

### ⚙️ Системные требования
* **.NET SDK 10.0** (или выше)

### 🔨 Сборка проекта
Выполните команду в корневой папке репозитория:
```bash
dotnet build CleverenceSoft.slnx
```

### 🧪 Запуск тестов
Покрытие кода юнит-тестами проверяется стандартным тест-раннером:
```bash
dotnet test
```

### 💻 Пример запуска консольного приложения (Задача 3)
```bash
dotnet run --project src/Task3/Task3.csproj <путь_к_входному_файлу.txt> <путь_к_выходному_файлу.txt>
```
